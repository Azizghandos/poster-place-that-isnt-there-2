A travel poster for NIMBARA, a fictional island floating above a sea of
clouds at golden hour: green cliffs, a white lighthouse with a coral-red
roof, a waterfall pouring off the plateau into the clouds, and a small
cluster of white houses with terracotta roofs.

## How to run

```sh
python3 make-image.py
```

This writes `entry.png` (1024×1024). The drawing is fully deterministic —
running the script twice produces byte-identical output.

`main.ts` copies `entry.png` to the make.fun output directory.

Get started with make.fun: https://make.fun/r/660zm28c
